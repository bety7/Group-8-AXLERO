MetricMind – Agentic Semantic BI Engine

Project Overview

MetricMind is a Data Analytics prototype designed to help users explore sales data, calculate business metrics, analyze regional performance, and obtain structured business insights.

The prototype demonstrates a governed semantic query layer that recognizes supported business questions, applies region filters, calculates approved metrics, and rejects unsupported queries.

Objectives

- Analyze sales revenue, cost, profit, and profit margin.
- Compare business performance across regions.
- Validate data quality and identify potential issues.
- Provide interactive business analysis.
- Maintain an audit log of analyzed queries.
- Apply basic metric governance and query safety checks.

Features

- Sales data analysis using Python and Pandas.
- Revenue, cost, profit, and profit margin calculations.
- Regional performance analysis and visualizations.
- Interactive business query dashboard.
- Data quality validation.
- Governed semantic query prototype.
- Query audit logging.
- Automated verification tests.

Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook
- CSV datasets
- ipywidgets

Project Files

- "MetricMind_Development.ipynb" – Main development notebook.
- "metricmind_sales.csv" – Sales dataset.
- "metricmind_metrics.md" – Metric definitions and documentation.
- "metricmind_regional_analysis.csv" – Regional analysis results.
- "metricmind_regional_insights.csv" – Regional business insights.
- "metricmind_business_insights.txt" – Business insights report.
- "metricmind_query_audit_log.csv" – Query audit records.

How to Run

1. Open "MetricMind_Development.ipynb" in Google Colab.
2. Upload or make available the required CSV files.
3. Run the notebook cells in order.
4. Review the data analysis, visualizations, business insights, and verification results.

Current Implementation

This project is a working prototype using a local sales dataset and rule-based semantic query processing. It demonstrates core analytics and governance concepts; it does not yet implement a production-grade agentic AI system, live data warehouse integration, or an external large language model.

Expected Outcome

MetricMind demonstrates how business metrics, regional analytics, query governance, and audit logging can be combined into a simple business intelligence workflow.
