MetricMind – Agentic Semantic BI Engine



Project Overview



MetricMind is a business intelligence prototype designed to answer business questions using consistent business metrics.



Objective



To demonstrate how business users can analyze sales performance using revenue, cost, profit, and profit margin.



Technologies Used



\- Python

\- Pandas

\- Matplotlib

\- Google Colab



Current Implementation



\- Created a sample sales dataset

\- Defined business metrics

\- Calculated revenue, cost, profit, and profit margin

\- Generated a regional revenue chart

\- Tested a predefined natural-language question



Dataset



The prototype uses synthetic sales data created for demonstration purposes.



Current Limitation



The current version uses predefined keyword matching. Integration with an LLM agent, a governed semantic layer, and a web-based BI interface remains future work.



How to Run



Open "MetricMind\_Development.ipynb" in Google Colab and run the notebook cells in order.



Project Status



Initial working prototype completed. Further development and team integration are pending.
